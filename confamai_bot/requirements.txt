# Confam AI WhatsApp bot — runtime dependencies.
#
#     pip install -r confamai_bot/requirements.txt
#
# Deliberately short. This process is a webhook receiver and an HTTP client: it
# runs no model, holds no greenbook data, and needs no GPU. Everything it knows
# about product verification arrives over the network from the N-ATLaS server.
#
# NOT needed here, unlike n_atlas_server/requirements.txt:
#   torch, transformers, bitsandbytes, accelerate  — the model runs on Kaggle
#   pandas, openpyxl                             — the greenbook is the server's
#   psycopg                                       — only for the supabase session
#                                                   backend, and even then only
#                                                   psycopg[binary]

fastapi>=0.115.0
uvicorn[standard]>=0.30.0
httpx>=0.27.0
python-dotenv>=1.0.0

# Required for WHATSAPP_SESSION_BACKEND=supabase, which is how the bot stores
# sessions in production. Not optional any more: without it the import fails at
# first boot rather than at install time, which is the worst place to find out.
#
# Installed unconditionally rather than behind an extra requirements file,
# because a deployment that must not lose conversation history on a restart
# should not have a working image and a broken one depending on which
# requirements file someone remembered to build with.
psycopg[binary]>=3.1

# ---------------------------------------------------------------------------
# Optional: local voice transcription (fallback only).
#
# A voice note is transcribed by the N-ATLaS server's
# /v1/audio/transcriptions endpoint by default, so this process needs no
# torch and no model — the four NCAIR1 models run on the server's GPU.
# See confamai_bot/audio.py and WHATSAPP_VOICE_TRANSCRIPTION.
#
# The local path (WHATSAPP_VOICE_TRANSCRIPTION=local, or the automatic
# fallback when the server is unreachable) does load the models here, and
# only then are these needed:
#
#     pip install torch transformers
#
# torch is multi-gigabyte and needs a matching CUDA build for GPU
# transcription, which is why it is not a hard dependency of a process
# whose job is receiving webhooks.
