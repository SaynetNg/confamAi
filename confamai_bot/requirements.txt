# Render's default build command for a Python service is:
#
#     pip install -r requirements.txt
#
# It runs at the repository root, where the dependencies do not live —
# they are in confamai_bot/requirements.txt. Without this file the
# default build command fails, so a service created with the defaults
# never gets past the build step.
#
# `-e .` (pyproject.toml at this root) installs the confamai_bot
# package itself into the virtualenv. That is what makes the start
# command
#
#     python -m confamai_bot --host 0.0.0.0 --port $PORT
#
# work regardless of the working directory Render runs it from: the
# package is importable because it is installed, not because the
# current directory happens to be the repository root. "No module
# named confamai_bot" is the failure this prevents.
#
# The dependency list itself stays in confamai_bot/requirements.txt —
# the single source of truth — and is mirrored in pyproject.toml for
# packaging. Keep the two in step when adding a dependency.
-r confamai_bot/requirements.txt
-e .
