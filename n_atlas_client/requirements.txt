# N-ATLaS laptop client — required Python packages.

# dependencies needed besides Python 3.10+.
#

#   python-dotenv  loads N_ATLAS_* from a local .env file

#                  withdrawn products become invisible.
#

#   pip install "openpyxl>=3.1" "psycopg[binary]>=3.1"
